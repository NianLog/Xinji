## 这份报告测什么

评测比较**记忆层**把什么交给了下游模型，不比较模型本身。四个 baseline与心记接收完全相同的对话流与治理动作，判分只看组装出的上下文：

| 指标 | 判分口径 |
| --- | --- |
| 事实召回率 | 应当想起的事实出现在上下文的比例（探针级） |
| 提及准确率 | 应暴露的暴露、不该暴露的沉默，合并正确率 |
| 越界率 | 边界有效且用户未提起时，被边界覆盖的事实仍在上下文的比例 |
| 删除后复活率 | 删除并强制重建派生层后，被删事实又出现的比例 |
| 阶段迁移正确率 | 脚本化关系阶段与策略记录阶段的一致率（baseline 无此机制） |
| 成本 / 延迟 | 上下文 token（均值 / p95）与上下文组装耗时 |

**口径说明（重要）**：无 LLM 参与判分。「越界」测的是上下文层面的*暴露风险*——被边界覆盖的旧事仍在上下文里，下游模型大概率主动提起；最终是否出口由模型决定。心记的成本包含其边界与分寸提示，baseline 无此开销。

## 已知边界与后续工作（探针测不到的缺陷面）

- **旧计划共现**：意愿变更后，被放弃的旧计划记忆仍在库中（时节触发已通过关闭话题规避），但显式问及旧计划时新旧行会同时出现在上下文——是否构成干扰由下游模型决定。计划引入记忆的时效标注（supersede 链）。
- **召回上限来自检索器**：LoCoMo 上 45.7% 的召回天花板源于「5 条 × BM25 词袋」装包策略；换向量召回或扩大 MAX_ITEMS 可换更高召回（更高成本），属工程权衡。
- **重申产生重复记忆**：同一愿望换一种说法会派生第二条事实记忆，装包已按话题去重，但账本层面未合并（保留原话可审计的代价）。
- **滑动窗口的「遗忘式合规」**：窗口基线越界 17.5% 是「该忘的还没忘、该记的已经忘」——它的低违规来自遗忘而非分寸，对比时需结合召回率读。
